# Пресет «русские домены»: сервисы, которые ведут себя иначе при зарубежном
# адресе - гео-ограничения, блокировки по IP, лимиты.
#
# Список собран по двум топам русскоязычных сайтов по аудитории (октябрь 2026) и
# намеренно не пересекается с domains.txt и domains-youtube.txt: тест на полноту
# пресетов этого требует, а хост, попавший в два пресета, измерялся бы дважды под
# разными именами. Зарубежные сервисы из тех же топов (Google, YouTube, Wikipedia,
# TikTok, WhatsApp, Telegram, Twitch, Reddit, Booking) сюда не входят - они не
# русские; взрослые сайты исключены, потому что дерево публичное.
#
# Остались только хосты, чей адрес отвечает из России: проверено 2026-10-15 по
# регистрации адреса (ip-api) и по пути (mtr с этой линии). Хосты за Cloudflare
# убраны по тому же признаку - у них видна страна края, и ни один замер отсюда не
# говорит, где их origin. У двух хостов, `www.nalog.gov.ru` и `wink.ru`, ip-api
# назвал германский адрес NGENIX, но трейс дошёл до российского узла (15-31 мс),
# поэтому они остались.
