# can answer it instead of the whole list.
#
# The rule is what a browser is told: no `Alt-Svc` naming h3, and no `alpn=h3` in
# the host's HTTPS record, with http3check.net agreeing on "no HTTP/3"
# (`scripts/quic/online_h3.py`; run 2026-10-02). A QUIC handshake answering is not
# support: `intodns.ai` read one as support and was wrong for three hosts that
# four other checkers and a browser agree serve no HTTP/3, so that column is gone.
# A host either source is silent about stays probed — silence is not an answer,
# and the question this column asks is exactly that difference.
